## Dataset

Place the Overhead-MNIST dataset under `data/version2/`, with `train/` and `test/` splits, each containing one subfolder per class:

- `ship/`
- `helicopter/`

The dataset contains 13,918 grayscale images across two classes (8,012 ship images and 5,906 helicopter images), split into `train/` (7,124 ship, 5,250 helicopter) and `test/` (888 ship, 656 helicopter).

The source project did not include the original image files.   
This dataset can be downloaded at: https://www.kaggle.com/datasets/datamunge/overheadmnist/data
